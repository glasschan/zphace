自動根據排版指南格式化中文文本。

== 描述 ==

此插件自動格式化 WordPress 文章、標題和自定義欄位中的中文文本，以提高可讀性和美觀性。它解決了常見問題，例如中文和英文字符之間的間距、正確的標點符號使用以及全形字符的轉換。

== 安裝 ==

1. 將 `chinese-text-formatter` 文件夾上傳到 `/wp-content/plugins/` 目錄。
2. 通過 WordPress 中的「插件」選單啟動插件。

== 常見問題解答 ==

= 此插件是否支援自定義欄位？ =

是的，該插件會自動格式化自定義欄位中的文本。

= 我可以自定義格式化規則嗎？ =

目前，格式化規則是預定義的，無法自定義。
